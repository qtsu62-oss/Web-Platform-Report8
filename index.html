لغة JavaScript وتفاعل صفحات الويب

المقدمة

لو فتحنا موقعاً ما وضغطنا على زر فظهرت قائمة، أو كتبنا في خانة بحث فظهرت اقتراحات فورية، فإن من يقف وراء هذه التفاعلات في الغالب هي لغة JavaScript. فبدون هذه اللغة تبقى صفحات الويب مجرد نصوص وصور ثابتة لا تستجيب لما يفعله المستخدم.

يشرح هذا التقرير باختصار ما هي JavaScript، وكيف تُضاف إلى صفحة الويب، وكيف تحوّل الصفحة الثابتة إلى صفحة تفاعلية تتجاوب مع نقرات المستخدم، مع مثال بسيط يوضح الفكرة. وتكمن أهمية الموضوع في أن تفاعل المستخدم مع المنصات الإلكترونية، مثل المتاجر والمنصات التعليمية، يعتمد عليها بشكل كبير.

عرض الموضوع

1. ما هي JavaScript؟

JavaScript لغة برمجة تعمل داخل متصفح الويب، وتُستخدم لإضافة السلوك والتفاعل إلى الصفحات. ويمكن تشبيه صفحة الويب بالجسم الحي: HTML هي الهيكل العظمي الذي يحدد المحتوى، وCSS هي الشكل الخارجي، أما JavaScript فهي الحركة التي تجعل الصفحة تستجيب لما يحدث.

اللغةدورها في الصفحة
HTMLتحديد المحتوى والهيكل: العناوين والفقرات والصور والأزرار
CSSتحديد الشكل: الألوان والخطوط والمسافات
JavaScriptتحديد السلوك: ماذا يحدث عند الضغط أو الكتابة أو تحميل الصفحة

2. كيف نضيف JavaScript إلى الصفحة؟

يمكن كتابة الكود داخل وسم script في الصفحة نفسها، أو في ملف مستقل بامتداد js يُربط بالصفحة، والطريقة الثانية هي الأفضل في المواقع لأنها تُبقي الكود منظماً ويمكن استخدامه في عدة صفحات:

<script src="script.js"></script>

3. كيف تتفاعل الصفحة مع المستخدم؟

يقوم التفاعل على فكرة بسيطة: ينتظر المتصفح حدوث حدث (Event) مثل نقرة المستخدم، فينفّذ الكود المرتبط به، وغالباً يغيّر شيئاً في الصفحة عبر ما يُسمى DOM، وهو تمثيل عناصر الصفحة بحيث تستطيع JavaScript قراءتها وتعديلها.

الحدثمتى يحدث؟
clickعند الضغط على عنصر مثل زر أو رابط
inputعند كتابة المستخدم في خانة إدخال
submitعند إرسال نموذج مثل تسجيل الدخول
loadعند اكتمال تحميل الصفحة

4. مثال عملي: زر يغيّر النص

نريد أن يتغير نص الفقرة عند الضغط على الزر. أولاً نكتب في HTML زراً وفقرة:

<button id="btn">اضغط هنا</button>
<p id="msg">مرحباً</p>

ثم نكتب في JavaScript:

document.getElementById("btn").addEventListener("click", function () {
  document.getElementById("msg").textContent = "تم الضغط على الزر";
});

خطوات التنفيذ: الدالة getElementById تبحث عن العنصر بمعرّفه، وaddEventListener تجعل الزر ينتظر حدث النقر، وعند حدوثه يُنفَّذ الكود الذي يغيّر نص الفقرة. فتتغير الصفحة أمام المستخدم دون إعادة تحميلها.

5. استخدامات JavaScript في المنصات الإلكترونية

  • التحقق من النماذج: مثل التأكد من كتابة البريد الإلكتروني بشكل صحيح قبل الإرسال.
  • القوائم والعناصر المتحركة: مثل القوائم المنسدلة ومعارض الصور.
  • تحديث المحتوى دون إعادة تحميل: مثل تحديث سلة المشتريات أو عرض نتائج البحث فوراً.
  • تخصيص المظهر: مثل الوضع الليلي الذي يغيّر ألوان الصفحة بضغطة زر.

6. الخلاصة

JavaScript هي اللغة التي تمنح صفحات الويب الحياة، فهي تستمع لأفعال المستخدم مثل النقر والكتابة وتستجيب لها بتغيير محتوى الصفحة أو شكلها فوراً. وتعلّم أساسياتها مع HTML وCSS خطوة مهمة لأي شخص يريد بناء منصات إلكترونية تفاعلية وسهلة الاستخدام.
